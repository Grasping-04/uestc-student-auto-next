# UESTC 课程自动下一节助手

适用于电子科技大学教学资源管理平台的 Tampermonkey 用户脚本。

脚本会监听当前课程视频，并在视频正常播放结束后尝试进入下一课件。它适合减少重复点击操作，不会代替用户完成测验、作业或其他课程活动。

## 功能

- 视频播放结束后自动进入下一课件
- 当前章节结束后继续进入下一章节的课件
- 进入下一视频后尝试自动开始播放
- 页面进入后台后保持课程视频播放，回到前台自动恢复
- 自动锁定 2 倍速播放，切换课件后依然保持
- 右下角校徽控制面板，一键管理所有功能开关
- 自动适配课程页面的动态加载
- 页面右下角常驻显示运行状态
- 支持通过校徽面板或 Tampermonkey 菜单启用、停用
- 不读取账号密码，不连接第三方题库服务

## 使用环境

- Chrome、Edge 等支持 Tampermonkey 的桌面浏览器
- Tampermonkey 扩展
- `https://resource.uestc.edu.cn/*` 下的课程页面

## 安装

### 一键安装（推荐）

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击 GreasyFork 发布页中的「安装此脚本」按钮：https://greasyfork.org/zh-CN/scripts/594234 ，Tampermonkey 会自动弹出安装确认。
3. 确认脚本开关处于启用状态。
4. 在 `管理扩展` 中开启 `开发者模式` ，并在 Tampermonkey 详细信息中点击 `允许用户脚本`。
5. 打开课程页面并按 `Ctrl+F5` 刷新。

### 手动安装（备选）

1. 打开 Tampermonkey 管理面板，选择“添加新脚本”。
2. 删除编辑器中的默认内容，复制 `uestc-auto-next.user.js` 的全部内容并粘贴到编辑器。
3. 按 `Ctrl+S` 保存，确认脚本开关处于启用状态。
4. 在 `管理扩展` 中开启 `开发者模式` ，并在 Tampermonkey 详细信息中点击 `允许用户脚本`。
5. 打开课程页面并按 `Ctrl+F5` 刷新。

## 自动更新

- 脚本发布到 GreasyFork 后，Tampermonkey 会每天自动检查一次更新（检查时机是打开课程页面时），新版本会自动安装，无需手动操作。
- 想立即检查更新：点击浏览器工具栏的 Tampermonkey 图标 → 管理面板 → 脚本「UESTC 自动点击下一节」右侧菜单 → 「检查更新」。
- 想调高检查频率：Tampermonkey 设置 → 「通用」→「脚本更新」→ 将「检查更新频率」改为更短的时间。
- 脚本发布页的代码与仓库保持同步：仓库每次 `push` 后，GreasyFork 会通过 Webhook 自动拉取最新版本（配置方式见「维护」章节）。

## 使用方法

1. 打开“我的课程”并进入需要学习的课程。
2. 手动选择第一节视频并开始播放。
3. 确认页面右下角校徽图标存在，点击校徽展开控制面板。
4. 等待视频正常播放结束。脚本默认阻止平台在页面进入后台时暂停视频，可以切换到其他窗口或标签页。
5. 脚本会自动尝试进入下一课件，并在新播放器加载后开始播放。

点击右下角校徽展开控制面板，可以快速开关「自动下一节」「后台保持播放」「锁定二倍速」三个功能。也可以通过 Tampermonkey 菜单中的对应命令进行控制。

### 控制面板

- **自动下一节**：视频播放结束后自动进入下一课件（默认开启）
- **后台保持播放**：页面进入后台时阻止平台暂停视频（默认开启）
- **锁定二倍速**：视频始终以 2 倍速播放，手动调速或切换课件后都会恢复为 2 倍速（默认开启）

校徽右上角的圆点表示自动下一节状态：绿色为启用，灰色为停用。校徽无法加载时会显示“U”字图标代替。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 等待视频 | 脚本已启动，但当前页面尚未检测到视频 |
| 监听中 | 已检测到当前视频，正在等待其播放结束 |
| 切换中 | 当前视频已结束，正在进入下一课件 |
| 等待新视频 | 已进入下一课件，正在等待播放器加载 |
| 播放中 | 下一课件已自动开始播放 |
| 请手动播放 | 浏览器阻止了自动播放，需要点击播放器 |
| 下一项无可播放视频 | 下一课件不是视频，或播放器未能在规定时间内加载 |
| 未找到下一课件 | 页面中没有可切换的下一项，或页面结构暂未适配 |
| 已停用 | 自动下一节功能已关闭，可在校徽面板或菜单中重新启用 |

## 已知不足

- 必须先手动选择并播放第一节视频。
- 脚本会阻止平台在页面进入后台时暂停视频，但无法阻止浏览器自身的限制（如隐藏标签页的定时器节流、Chrome 对长期隐藏且无声音标签页的冻结）；因此暂停的播放会在回到前台后由脚本自动恢复。
- 脚本会尝试自动播放下一视频，但浏览器的自动播放策略仍可能要求用户手动点击播放器。
- 仅处理视频结束后的课件切换，不会自动完成文档、测验、作业、考试或弹窗确认。
- 到达课程最后一项后不会继续跳转。
- 平台更新页面结构后，自动切换功能可能需要重新适配。

## 可选：使用 DeskPins 保持窗口可见

脚本默认已阻止平台在页面进入后台时暂停视频。若“后台保持播放”被关闭，或平台对前台状态有更严格的检测，仍可尝试使用 Windows 上的 DeskPins 将课程窗口置顶：

1. 将课程页面单独打开在一个浏览器窗口中。
2. 启动 DeskPins。
3. 选择 DeskPins 的图钉工具，然后点击课程窗口。
4. 调整课程窗口大小，确保视频区域保持可见。
5. 不要最小化课程窗口，也不要在该窗口中切换到其他标签页。

DeskPins 只能帮助窗口保持置顶，无法保证兼容平台的所有前台检测方式。请从可信来源获取软件，并遵守平台和课程的使用要求。
下载地址：https://efotinis.neocities.org/deskpins/

## 维护（脚本更新流程）

脚本代码以本仓库为唯一主源，GreasyFork 发布页通过官方 Webhook 自动同步：

1. 修改 `uestc-auto-next.user.js` 并提交推送（注意同步递增 `@version`）。
2. 仓库 Webhook 自动通知 GreasyFork，GreasyFork 拉取 raw 地址的代码并更新发布页。
3. 用户浏览器按「自动更新」章节的机制升级到新版本。

发布页「代码同步」配置（发布时设置一次即可）：

- 同步 URL：`https://raw.githubusercontent.com/Grasping-04/uestc-student-auto-next/main/uestc-auto-next.user.js`
- 同步类型：自动

仓库 Webhook 配置：在 GitHub 仓库 `Settings → Webhooks → Add webhook` 中填写 GreasyFork 提供的 Payload URL 与 Secret，触发事件选 `Just the push event`，内容类型为 `application/json`。具体数值在 GreasyFork 设置页的「Webhook 信息」中生成。

## 常见问题

### 页面没有显示校徽控制面板

- 确认 Tampermonkey 中安装的是最新脚本并已经保存。
- 确认脚本处于启用状态。
- 检查浏览器是否允许 Tampermonkey 访问当前网站。
- 在课程页面按 `Ctrl+F5` 强制刷新。

### 如何更新脚本

- 从 GreasyFork 一键安装的脚本默认自动更新（见「自动更新」章节），无需手动操作。
- 手动安装的脚本不会自动更新，需要重新按「手动安装（备选）」的步骤覆盖粘贴。

### 进入后台后视频仍然暂停

- 确认 Tampermonkey 菜单中的“后台保持播放”已开启。
- 浏览器自身的限制（隐藏标签页定时器节流、Chrome 冻结无声音标签页）无法被脚本绕过；回到前台后脚本会自动恢复播放。
- 若正处于“请手动播放”状态，回到前台后脚本会重新尝试自动播放。

### 一直显示“等待视频”

请进入具体视频课件并手动开始播放。如果播放器已经出现，可以刷新页面后重新进入该课件。

### 视频结束后没有进入下一项

按 `F12` 打开开发者工具，在控制台中搜索 `[UESTC Auto Next]`。提交问题时请附上：

- 当前课程页面 URL
- 校徽面板中显示的状态
- 相关控制台日志
- 浏览器及 Tampermonkey 版本

请勿提交 Cookie、Token、密码或其他账号信息。
